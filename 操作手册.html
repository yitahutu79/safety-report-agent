安全设施设计报告工作台操作手册

最后更新：2026年11月26日。对应当前 main 分支工作台；适用于 Windows、macOS 本地环境及已部署工作台的公司项目组。

本手册是操作说明的统一来源；同目录的 操作手册.html 由本文件生成，可离线打开、搜索及打印。更新代码后请同时更新两份手册。

快速找到操作

要做什么 入口与说明
换主题、字体或字号 右上角“外观”，见外观与阅读设置
上传本项目文件 左侧“资料管理 → 资料导入”
找项目事实及完整原文 “基本信息”“项目结构化数据”；图纸在“图件与位置”
维护通用法规和规则 “知识中心 → 共用知识维护”
根据资料直接提问 “知识中心 → 知识问答”；参考来源可展开
修改一个小节 “报告编制 → 编写与修订 → 编写助手 → 按小节修改”
放入原表、图片 编写区“编辑正文”，展开原表工具或“文档图片库”
做专业审核 “报告编制 → 专业工作台”
保存本轮修改、下载报告 编写区统一保存版本；总稿使用“检查并组装总稿”
查看已经做过的测试 左侧“项目交付 → 测试记录”

日常流程：启动 → 选择项目和模型 → 上传并读取 → 核对资料 → 确认目录 → 逐小节编写、暂存与锁定 → 保存本轮版本 → 检查并组装总稿 → 下载和人工审核。

仅更新网页样式或脚本时，保存正在编辑的内容后刷新即可；后台程序或依赖更新时，等待任务结束、保存编辑，再按部署方式重启服务。不要在生成中强行停止后台。

1 启动与进入工作台

Windows 首次使用时，双击 初始化Windows环境.cmd 安装项目独立依赖；以后双击 启动工作台-Windows.cmd，等待浏览器打开。结束使用前先保存编辑、等待当前任务完成，再双击 停止工作台-Windows.cmd。

macOS 在 Finder 中进入项目目录，双击 启动工作台.command；结束使用时双击 停止工作台.command。

若浏览器未自动打开，访问 http://127.0.0.1:8765。更新后请刷新页面。电脑重启或退出系统登录后，下次使用需再次启动工作台。无需保持聊天或 Codex 开启。

127.0.0.1 仅指当前这台电脑。同事共用需要公司服务器地址，不能把这个本机网址直接当作公司共享地址。

2 先配置并选择编写模型

不配置模型只能生成编写提纲，不能自动写出完整的报告正文。

  1. 点击左侧“模型设置”，或者“编写与修订”中的“配置或添加模型”。
  2. 在“已保存配置”选择“添加新模型”。
  3. 选择服务商：DeepSeek、通义千问、本机 Ollama 或自定义兼容服务。
  4. 填一个容易识别的配置名称，例如“公司报告编写模型”。
  5. 检查 API 服务地址。百炼的地域与工作空间地址需要和自己的 Key 匹配。
  6. 输入自己的 API Key。本机 Ollama 通常不需要 Key，但需要提前运行模型服务并安装模型。
  7. 点击“获取模型列表”，在“模型 ID”中选择；供应商不支持列表接口时，填写其控制台提供的准确模型 ID。
  8. 点击“测试连接”。它只发送一条测试文本，不发送项目资料。
  9. 测试通过后点击“保存并选用”。随后可以在编写区域切换已保存的模型。

Key 在设置窗口填写即可，不要发送到聊天中。服务端保存设置，重启后仍可使用；页面不会回显已经保存的 Key。修改已有配置时，Key 留空表示保持；更换服务地址或服务商时需重新填写，避免把原供应商密钥发给新地址。

模型来自你配置的服务，而非程序自带的免费大模型。保存成功表示配置已保存，不等于连通性和正文质量已验收；建议先测试连接，再用演示项目验证编写效果。

3 继续已有项目 不需要重新开始

进入页面后，点击左侧已有项目即可。原来的上传文件、手工填写和旧草稿保留在项目中。

  1. 在“资料导入”中查看文件列表和读取状态。
  2. 需要补充资料时，继续点击“选择文件”或“选择文件夹”。
  3. 同一个内容的文件会跳过重复导入；某个文件无法接收时，其余文件仍继续导入。
  4. 点击“读取新增资料并更新信息”。系统复用已读取的资料，保留人工填写的字段。
  5. 新资料出现不同候选值时，相关字段会提示重新核对，不自动用新值覆盖旧值。

补充资料只会提示草稿需要更新，不会删除旧草稿或下载文件。之后可只改有关章节，也可以直接编辑一段文字。

4 导入时选择正确用途

用途 适合什么资料 系统怎么使用
自动识别用途 混合文件或整个文件夹 按格式及名称初步分类，之后可以调整
本项目事实资料 项目说明、工艺、设备物料清单、备案等 可读取的文字用于事实提取与编写
参考报告或文风样例 上一个项目的报告、写作样例 保留为参考，不把其中企业和参数作为新项目事实
需要放入报告的图件 地理位置图、消防图、设备布置图等 设置图题、页码和是否放入 Word
仅归档原始附件 CAD 原图、暂不能解析的办公文件等 保存并支持原文件下载，不声称已经读懂

文件列表中的用途下拉框可以修改分类。“暂不使用”会使文件退出本次编写范围，保留文件本身；需要时点击“重新纳入”。变更事实资料范围后，要重新读取。

每个文件最大 80 MB；一个项目最多 100 个文件、总计 600 MB。Word、PDF 和文本资料可解析，图片可作图件。旧 DOC、部分办公格式和 CAD 原图可归档，但需要转换后才能用于正文读取或图件嵌入。

5 核对项目基本信息

读取后，系统显示建设单位、项目名称、项目地址、建设性质、生产规模、总投资和建筑面积。

  1. 对照原资料检查候选值，缺项可以手工填写。
  2. 正确的字段勾选“已核对”；也可以在检查完所有已填写内容后，点击“确认已填写项”。
  3. 点击“保存信息”。修改字段后需要重新核对。
  4. 生成时若仍有已填写但未确认的字段，会弹出确认窗口，而不是忽略这些字段。
  5. 可选择“返回核对”，或确认弹窗列出的内容后继续。

建设单位和项目名称必须填写。其他未提供的参数不会自动编造。展开“资料出处与读取提示”查看文件读取问题、候选来源和资料片段。

“使用所选模型辅助提取基本信息”是可选项。勾选后点击读取，会将相关资料片段发送到所选模型；不勾选时使用本地提取和人工核对。

6 导入已有图件与工程文件

点击“已有图件与位置资料”右侧“上传图件或原图”，可直接选择已有文件，不必重新画图。

文件类型 可以做什么
PNG、JPG、WEBP、BMP、TIFF 预览、设置图题、选择放入 Word
PDF 图纸 预览指定页、按页码选择并转换为图片放入 Word
DWG、DXF 保存原图并下载；先从 CAD 导出 PDF 或图片后，再上传用于预览与嵌入
SVG 保存原图；当前请先转换为 PNG 或 PDF 用于 Word
DWL、DWL2 自动跳过，提示寻找同名 DWG 或其 PDF/图片版本

DWL/DWL2 是 AutoCAD 创建的临时信息文件，不是实际图纸。不要通过改后缀把它当作 DWG。

每张图件可以设置图题、PDF 页码，并勾选“放入报告”，然后点击“保存图件设置”。PDF 页码可以写 1、1,3-5，每个文件最多选择 20 页。

预览时请检查图纸是否完整、方向是否正确、文字是否清晰。图件设置保存后，重新生成草稿或点击“保存本轮修改并生成版本”，导出的 Word 会使用当前选择的图件。历史版本保留当时已导出的图件，不随新设置变化。

没有现成图件时，可以展开下方工具，生成工艺流程图或在配置地图服务后获取位置图。图片/PDF 图件的接收和展示，不等于已经进行图纸内容理解或工程尺寸识别。

资料版本、知识库与措施承接

  • 在文件列表点开“资料类型、来源、日期与版本”，为备案文件、SDS、综合分析报告、图纸等补充类别、来源、出具日期和版次。保存后如这些材料用于正文，应重新读取资料；冲突值仍需在项目事实区人工确认。
  • 进入“知识中心 → 共用知识维护”维护跨项目可复用的法规标准、危险物料、分析规则、安全措施、报告规则和案例。核对来源、适用范围及版本信息；新条目先是“待审核”。审核确认可用及报告依据的有效性要求，见后文“一次审核确认可用”。编辑已批准条目会生成新修订并退回待审核。
  • 生成报告时知识库用于支持一般依据、规则和方法，不能证明当前项目事实。法规有效状态需由有职责的人员核实，可在“联网发现与更新”查找官方更新线索，但不会自动替换或批准库内法规。
  • 在“安全对策措施承接台账”把综合分析报告设为相应资料类型并重新读取后，可抽取建议候选；候选仍需逐条核对来源页码和原文。选择采纳状态，填写设计落实内容或不采纳理由、确认人后保存。只有已决定条目会提供给第 4 章；“待确认”不会被表述为已采纳。

专业分析与计算复核

在“专业工作台 → 计算复核”进入“专业分析与计算复核台账”。可登记危险因素、危化品、重大危险源、防火间距、爆炸危险、泄压面积和消防用水等记录。每项都可保存输入、来源文件/位置、法规/标准版本和条款、公式/判定方法、过程、结果、假设及复核人。只有“专业复核通过”的记录才进入报告检索；修改通过记录会自动退回待复核。

其中“重大危险源辨识指标 S”提供了 GB 18218-2018 的确定性计算入口：单一品种按 q≥Q，多品种按 S=Σ(qᵢ/Qᵢ)，数量和临界量均以吨录入。先填写生产/储存单元及边界来源，再逐种填写实际存在量 q、临界量 Q 和各自出处。系统只负责算式，不自动识别化学品或查表选 Q，也不自动划分单元或做重大危险源等级分级。计算会先保存为待复核；专业人员核验物质类别、标准表项、数量口径和单元边界后，填写复核人并选择“专业复核通过”。还支持人工选定参考值的距离差值、厂房计算段泄压面积、单个火灾场景消防用水量辅助计算。距离差值不自动选条款或认定合规；泄压面积需专业人员先确认公式及分段条件；消防用水工具不自动确定消防水池最终容积。其他判断可在台账记录，计算完成仍为待复核。

7 第一次智能编写

  1. 在“编写与修订”中，选择已经配置的“编写模型”。
  2. 选择“智能编写正文”。
  3. 新项目建议选“只生成或重写所选章节”，先选一章；如果确实要一次处理全部内容，再选择“全部章节”。
  4. 在修改要求中说明本章需要回答什么，例如“先归纳本项目适用依据，再说明适用范围和与项目的关系；资料不足处列为待补充，不要粘贴原文”。
  5. 点击“生成并预览新版本”。系统会先按本次选择的章节检查资料；发现缺项时弹出补充窗口，可填写已核实信息，也可暂时跳过。回答会标记为待核实并只传入对应章节。
  6. 继续后检查该章的事实、分析、缺口和文字是否可读。满意后切换到下一章继续生成；需要补资料时先上传并读取新增资料，再只重写受影响章节，无需从头来过。
  7. 全部章节完成后再下载完整 Word；未生成或失败章节会显示待完成提示，不会夹带旧版摘录正文。

资料摘录只用于查证。智能编写由 LangGraph 编排资料规划 Agent、项目证据检索、报告撰写 Agent 和质量审核 Agent；审核失败时最多自动返修一次。草稿编辑区的“本章 Agent 工作记录”可查看角色、动作和检查结果，不包含模型隐含推理。每章至少会多一次规划模型调用，可能增加生成时间和模型费用。智能编写会筛选、归并证据并重新组织成报告正文。模型若返回编辑记录，核对清单会展示记录及出处；部分模型不返回附加记录时，系统会根据正文引用整理清单，并标明其来源。系统检查资料摘录标记、表格原文混入正文和段落与来源过于相似的情况；发现问题后会要求模型从头撰写，不再把不合格草稿作为改写底稿。仅修订部分章节时，检查只针对本次重写的章节；未选择的旧章节保留原样，可以之后单独修订。若重写后仍未通过，该章保留原稿并显示失败原因，其他成功章节仍可保存。生成失败时，页面会保留具体提示。这些检查不能代替对事实、逻辑、专业设计和技术结论的人工审核。

升级前的旧稿不会被自动覆盖。打开旧报告时，如果标记“旧版草稿 · 待重新编写”，可以从最需要改善的章节开始逐章重写，也可以选择“全部章节”。系统会保留当前旧稿作为历史版本；生成未通过时仍可查看并回到旧稿。失败或未通过检查的旧版正文不会混入新导出的 Word。

“仅生成编写提纲”不调用模型，只整理写作框架与已确认信息，不再把资料全文拼贴成报告。提纲和正文草稿会在页面及 Word 标题中明确区分。

8 已有一版后怎么继续修改

情况一 只改几句话或补充一段

  1. 打开“编写与修订”，选择有关章节。
  2. 在文本框中直接修改文字。
  3. 新增内容时点击“补充一段内容”，选择所属小节并填写。
  4. 表格内容可以直接修改；需要新增设备等记录时，点击表格下的“增加一行”。
  5. 点击“暂存当前编辑”保存进度；本轮全部修改结束，再点击“保存本轮修改并生成版本”。其余章节保留。

切换编辑章节时会暂存当前修改。页面关闭或刷新前仍建议主动点击“暂存当前编辑”。暂存不产生可下载版本，最后统一保存本轮修改；历史版本可在“历史版本”中下载。

情况二 补了一份设备清单 只让模型改相关章节

  1. 回到“资料导入”，继续上传新清单。
  2. 点击“读取新增资料并更新信息”，核对发生变化的字段。
  3. 打开“编写与修订”，选同一模型或另一个已保存模型。
  4. 选择相关章节；只修改部分内容时，在“编写助手 → 按小节修改”勾选有关小节。
  5. 填写自然语言修改要求，例如“保留项目背景，依据新设备清单更新本小节，不改其他小节”，点击“重写所选小节”。确需修改整章时使用“重写整章”。
  6. 检查编辑区结果，暂存当前编辑；本轮处理完成后统一点击“保存本轮修改并生成版本”。

服务端会把原章节作为修订底稿。未选章节原样保留；新版本保留旧内容需要的证据快照。只改部分章节不代表其他章节已经对新资料重新审核，页面可能继续提示资料有更新。

情况三 生成时补充缺少的材料

  1. 点击生成后，系统会自动检查本次所选章节；发现资料缺口时弹出补充窗口，无需先点单独检查按钮。
  2. 模型根据章节结构、已读取资料和已有草稿，列出“必须 / 建议 / 先确认适用性”的材料清单。
  3. 在窗口逐项填写已核实的信息，再点“补充后继续生成”；没有资料时可点“暂时跳过”，缺口会保留在报告中。
  4. 如果要先上传文件，返回后上传并读取新增资料，再次生成受影响章节。只会处理本次选中的章节。

清单是模型给出的准备建议，不是法规要求清单。通过模型询问时会发送本章缺项、核对事项和少量相关资料片段；答复会作为待核实证据用于当前章节。

增加或删除章节

在草稿编辑区点击“新增章节”，输入标题后即可填写正文、提示词或让模型按章编写。点击“删除本章”会在确认后保存为新版本；删除模板章节会改变报告结构和导出内容。所有结构变更都可以在“版本记录”中恢复旧版。

情况四 新版本没有上一版好

  1. 打开“版本记录”。
  2. 可以直接下载各版 Word 和核对清单作比较。
  3. 找到合适版本，点击“恢复为新版本”。
  4. 确认后，该版内容成为当前草稿，原来各版仍保留。

恢复报告不会把新上传的资料删除或退回旧资料。选定旧稿后，可以继续基于现有资料修改。

10 PDF 扫描件与无法读取的文件

本机新版已安装文本 PDF 解析、图片处理和 PDF 图件渲染依赖，启动入口会优先使用项目自己的 .venv 环境。

扫描件没有文本层时，仍需要 OCR；当前没有把 OCR 能力冒充成已读取的文字。PDF 可以作为图件展示，并不代表其中所有文字、表格和尺寸都已被准确提取。请查看逐文件读取状态和提示。

旧版 Word DOC 如需提取正文，请在 Word/WPS 中另存为 DOCX。损坏、加密或内部格式不匹配的文件，需要修复或重新导出。失败的文件不会阻断同批次其他文件的接收。

11 保存 备份与停止

资料、配置和版本保存在项目根目录的 data/。模型密钥也在此目录的服务端设置文件中，备份应由项目管理员保管。

  1. 等待任务结束，保存当前编辑。
  2. 按当前平台使用停止入口，或由部署人员停止服务。
  3. 备份整个项目文件夹，或按 README 中 Docker 卷备份方式操作。
  4. 下次双击启动，继续选择左侧项目使用。

生成过程中停止

生成新版本时，页面进度栏会显示“停止生成”。点击后会中断当前模型请求，并丢弃这次尚未完成的新版本；上一版草稿和历史版本保留。已发出的模型请求可能已产生少量用量，具体由模型服务的计费规则决定。若模型服务不支持流式响应，停止信号会在该次响应结束后生效。

升级前的源码和项目数据另有升级备份；不要把 backups/ 当作可随意删除的临时资料。不要在运行时手工改 data/ 中的文件。

模板正文复用与逐章确认组稿

在资料导入的“报告模板”中上传并确认目录后，点击“审核模板正文与复用方式”。按章节筛选段落，选择仅参考、审核后原文复用、结合本项目改写或不使用；填写适用对象和条件，勾选专业准确性及项目适用性确认后保存。每次保存一段；批准的固定段落在对应章节生成时原样组装，不重新措辞。模板不能证明当前项目的实际设施或隐患，厂名、参数、法规版本和专业结论须重新核对。

在草稿编辑页逐章编写与修改，满意后点击“确认本章并锁定”。锁定后不能重写或手工覆盖；修改前先解锁。基础数据、来源或台账变化会显示复核提醒，核对无影响可重新确认，有影响则解锁修订。上下移动章节改变总稿顺序；标题原编号保留，需校对编号及文内交叉引用。

所有章节完成并确认后，点击“检查并组装总稿”。先处理未完成、未确认、缺资料、来源失效和一致性阻断项；查看提示后组稿，再下载 Word。组稿直接使用现有章节，不调用模型。组稿时通过排版组件更新目录页码并生成同版PDF；跨电脑字体变化可能引起重排，可在Word中再次更新目录。最终专业审核、定稿及签章由负责人员完成。

专业工作台和已有目录修改

侧栏“专业工作台”统一提供“风险与专业判断”“计算复核”“措施落实”。在“待审核与关联记录”中可前往原记录审核，也可将已有计算或措施关联到分析记录。填写引用用途即可，无需复制结果。原记录更新后会提示引用版本变化；核对原记录后更新引用，失效关联处理前不能最终组稿。

草稿页展开“目录管理 · 编辑、新增或删除章节”，选择要修改的章节。主章节保留编号，可修改标题文字；小节可改名、新增和上下调整。保存后创建新版本，正文和来源保持，后续生成使用新目录。可删除带内容的小节，保存目录时需确认同时移除对应正文和表格，旧内容仍可从历史版本找回。锁定章节需先解锁。标题修改不自动重写正文中提到的图号、表号及交叉引用。

上传资料时展开“资料应该上传到哪里”查看说明：具体项目材料上传至项目资料区；公开通用依据和知识上传至共用知识维护区，导入后审核；报告目录及排版样例使用报告模板入口。

项目结构化数据与缺省目录（2026-11-24）

资料仍只需上传一次。备案、资质证照、人员名单、特种作业证、设备台账、检验报告、事故和隐患记录、MSDS、工艺及总平图上传到当前项目；上传后可核对资料类型。文件名识别仅作分类建议，不等于内容已经核验。公司私密数据不应上传至共用知识库。

  1. 在“资料导入”上传并点击“读取新增资料并更新信息”。
  2. 进入侧栏“项目结构化数据”，选择来源文件，以及法规标准、危险有害因素、安全设施、项目基础信息与资质、对策措施、应急组织与资源之一。
  3. 点击“提取相关内容为候选”。系统按主题检索最多8块、总计不超过10000字符的相关证据，显示发送模型的目的地，可停止。不是全文穷尽提取；某类别没有结果时可选择其他类别或补充可读取材料。
  4. 按原文小节查看完整内容块，修改有差异的内容；勾选要核对的块，在顶部统一填写核对人和说明，点击“批量核对通过”。可先保存为待分配章节，分配后用于对应章节。未核对的候选不供结构化证据编写使用；转录核对不代替专业判断复核。
  5. 按章编写时，核对通过的记录作为该章的有来源证据。来源停用、移除或版本不符的记录不再供新生成使用，已有章节需根据变更提醒复核。

六类是逻辑分类，不是六个独立数据库。共用知识库补充了安全设施、应急组织与资源的通用知识分类，仍须审核后检索；当前项目的设计参数、人员和物资数量不会自动加入共用区。扫描件需要OCR，CAD图纸需要可读取文字或转换件，当前功能不等于自动理解图形。

未上传模板的新项目，按报告类型使用用户“工作资料/大纲设计”中的参考目录。该文件包含七类大纲；没有独立安全预评价大纲，预评价保留原目录。已有项目保持目录不变，可在“报告模板”选择“恢复默认模板”显式采用新版参考大纲。上传并确认的模板优先。参考大纲不是法规符合性认证，目录、分析条件和专业结论仍需确认。

目录增删改（2026-11-24更新）

进入“编写与修订”，找到“目录管理”；已有草稿时展开“目录管理 · 编辑、新增或删除章节”，无需重新生成正文。

  • 在“选择章节”中选择主章，可修改主章节标题和各小节标题，点击“保存当前章目录”。主章保留原编号；小节使用1.1或1.1.1形式，必须有对应父标题。
  • “新增小节”添加二级标题；每个二级标题旁的“下级小节”可添加三级标题。标题可直接输入，箭头调整同章目录顺序。
  • “删除小节”先移除该目录行，点击保存后生效；带下级目录时一并移除，带正文或表格时另行确认是否删除内容。
  • 在“新增主章节”输入未占用的编号及标题，点击新增立即保存；“删除当前章”确认后立即保存。至少保留一个主章。
  • 已有草稿的修改保存为新报告版本，历史版本保留。未生成正文时仅保存目录，不调用模型。锁定主章须先解锁，才能修改或删除。
  • 目录保存后，后续按章编写使用新目录。改动不会自动重写文内交叉引用或迁移图件及专业记录，应检查其位置。

逐小节检查与编写（2026-11-24）

选择需要编写的章节后，系统先逐个小节检查资料缺口，再按目录逐个小节编写。二级和三级标题分别执行，不合并相邻标题。资料检查与正文小节均有断点缓存；相同资料、模型、目录和修改要求下重试，恢复已完成的节点。资料或设置变化会重新执行受影响流程。

每次调用重新分配该节点的输出额度；不等于模型额度无限，也不保证单个复杂小节永不截断。单节输出失败时只进行有限重试，保留其他完成的小节，页面显示当前检查或编写的小节。小节正文先保存任务断点；进入编辑区后，局部修改按本轮暂存和统一保存流程处理，不能把任务断点当作可下载版本。没有小节的主章仍作为一个单元处理，可先在目录管理中拆分。

指定小节改写（2026-11-24）

在“编写与修订”选择已有报告章节，在右侧“编写助手 → 按小节修改”勾选一个或多个小节，填写上方自然语言修改要求，点击“重写所选小节”。前置资料检查也只针对所选小节；补充信息或选择暂时跳过后继续。默认包含父标题的下级小节；取消“包含所选标题的下级小节”后可只处理选中的标题。原“重写当前章节”已改名为“重写整章”，两个操作范围不同。

成功后先进入编辑区及本轮暂存，只替换所选标题下的正文和表格，其他小节内容及其相对顺序保留。本轮全部操作结束再点击“保存本轮修改并生成版本”，不会每改一个小节就生成一个下载版本。失败保留原报告，章节锁定时不能局部改写；已变更版本或失效的小节选择会提示刷新。新增小节尚无正文时也可单独选择编写。局部修订不会自动清除全章其他缺项或失败标记，最终仍须核对完整性并确认章节。

已上传资料、自动结构化与正文复用（2026-11-24）

点击“读取新增资料并更新信息”后，系统读取项目事实资料、图纸文字层以及参考报告正文。参考正文单独保留来源类别，不直接当作当前项目事实。资料导入区显示项目证据块、参考正文块、结构化候选和正文复用候选数量。

“项目结构化数据”自动出现六类本地规则候选，不消耗模型token。规则识别主要用于初步分类、显式字段和原句留存，并非完整专业抽取；已取消每文件每类别40条的上限；候选数量仍不等于准确率或覆盖率。按类别、来源文件查看，对照原句核对，填使用章节及说明后保存；需要更精细提取时再调用模型。

“审核可复用正文”打开参考报告及模板的段落候选，可搜索、分页，并选择目标章节/小节。通用固定内容可在核对适用条件后选择“审核后原文复用”；含企业、具体参数或法规版本等内容应选择结合项目改写或仅参考。原文复用由系统原样组装，不重复要求模型改写。停用或移除来源后不再供新生成复用。

资料检查会同时查看上传清单、已确认信息、结构化核对记录和相关正文。匹配到已上传的材料时，提示核对具体字段、版本及适用性，而非一律重复上传；无法读取和检索未确认也会区分。命中标题时检索标题下的正文，原文引用位置保持。

如果上传的“正文+附件”属于当前项目的历史报告，而不仅是模板，请在资料用途选择“本项目事实资料”并重新读取；随后核对项目基础信息及冲突。其他项目报告仍应保持参考用途。旧DOC、扫描页和没有文字层的图纸可能需要转换或OCR；上传完成不代表所有页均成功读取。

完整报告直接复用与批量核对（2026-11-24）

如果上传文件就是本项目完整报告，可在资料列表勾选“本项目完整报告来源”。这是一次来源用途确认，不等于原件真实性或法规有效性审核。对应标题能匹配且未填写修改要求时，系统原样组装正文和表格，不调用写作模型；已有报告所含内容不再因缺少备案扫描原件被阻挡。填写修改要求后仍按要求进行模型改写。原件核验放在审阅清单，源报告的关键事实和结论仍需专业审核。目录不匹配或来源中没有对应内容时，不能保证直接复用。

结构化核对不再逐条重复填核对人：先逐条勾选，或点击“选择当前筛选结果”（跨页），也可“选择全部待核对记录”。统一填写一次核对人及说明，点击“批量核对通过”。可以不指定章节，先保存为“已核对，待分配章节”；分配章节后才参与结构化证据编写。批次中任一记录过期或来源失效会拒绝整批，刷新后再处理，避免只保存半批。

结构化字段和完整正文是两种用途。长正文不需要先被抽成字段，更不需要逐段签名后才能从已确认完整报告复用。已取消每类40条自动候选限制，长行按句识别；规则未识别出的内容仍保存在原报告全文中。

目录正文识别与底部分页（2026-11-24）

结构化记录不再将Word目录条目和孤立章、节标题作为事实候选。目录末尾页码不是正文；现有未审核的此类误提取已归档，不删除原文或人工审核记录。选择父小节（例如1.2）默认包含下级小节正文，可通过“包含所选标题的下级小节”复选框关闭；预检查、改写和完整报告复用使用相同展开范围。

结构化记录、参考正文复用两个列表的分页按钮均位于内容底部。点击上一页或下一页后自动定位新页首条，批量选择仍可跨页保留。

完整段落与PDF换行（2026-11-24）

项目结构化数据现在默认展开“完整原段（N字，可复用正文）”。标题只是摘要，省略处显示省略号；正文原段独立保存，不能用标题长度判断是否提取完整。PDF物理换行不再直接作为记录边界，储存、操作等段落按章节和段落分隔组合，保留来源页码及原始文字。Word多句段落从完整文档块读取，不受2200字符检索块限制；常规段落可保留几百到几千字。

未经人工修改审核的旧短碎片已归档，由完整段落替换；人工修改或审核记录保留原字段、原引句和历史，并补充完整上下文。新补充上下文是原文件内容，不等于新增内容已获得专业审核。记录数可能减少，因为多行碎片被合为完整段落，原文件正文没有删除。超长段落按句末边界分段，字段当前支持12000字符；没有可安全切分位置的超长原文仍可在完整报告来源中读取。

以完整小节核对结构化资料

读取资料后，系统尽量按原文小节保留法规清单和连续段落，同一块统一编辑和核对。旧项目进入“项目结构化数据”，点击“按原文小节重新整理”即可本地整理，无需重新上传或调用模型；已人工修改和已核对的记录保留。每块默认仅显示主要内容，其他字段和原文出处点击展开。核对人、核对说明在顶部统一填写；编辑需调整的块后勾选，点击“批量核对通过”一次保存。不指定章节时只完成转录核对，指定章节后参与该章写作。

整份PDF或图片作为原件附录

在“资料导入”找到文件，展开“原件附录”，可选“整份附在报告后，不提取拆分”，或“整份附在报告后，同时提取用于分析”，再点击“保存附录设置”。下次保存草稿或最终组稿时，Word末尾加入整份PDF各页或整张图片，按原顺序保留页图、颜色、表格及危险图标，不受普通图件最多20页的限制。原始文件可单独下载；Word内为原页图像，不是重新排版的可编辑正文。选择仅附录时不再列出该文件的结构化待核对记录，历史仍保留；切换分析用途后需重新读取资料。旧版文字不会因升级自动改写，请重新读取后整理候选。整份附录可能增大Word体积。Word原件请先转换为PDF再选此方式。

直接复用Word原表

进入“编写与修订”，展开“复用资料中的原表”，点击“读取可复用原表”，选择原表；可点击“放大查看原表”检查行列和合并单元格。选择需要插入的报告小节，点击“将原表插入所选小节”。插入结果先留在本轮编辑中；统一保存本轮修改后生成版本，不调用模型、不重写整章。来源文件和原表位置随表保留。相同来源的旧版原样复用表可升级为合并结构；已人工修改的旧表不会被自动替换。同小节重复插入会提示已有表格。锁定章节须先解锁。

复用后可直接编辑表格中的合并格，保存时同步其从属行；若新增行改变了原结构，将使用普通表格保存，内容仍保留。Word表格字体与边框按报告统一样式输出，保留行列、列宽比例及合并关系，不是逐像素复制原Word样式。PDF表格和含图片、嵌套表、对象的Word复杂表请使用PDF原页附录。

逐小节编辑，完成一轮后统一保存

  1. 进入“编写与修订”，在“当前编辑小节”选择要处理的小节。点击“重写所选小节”后，结果先进入编辑区，不生成下载版本。
  2. 阅读并修改；“暂存当前编辑”只保存本机编辑进度，不生成Word文件。切换章节、点击“下一个小节”或确认锁定前也会暂存手动修改。
  3. 满意后点击“确认并锁定本小节”，再点击“下一个小节”。锁定的小节不能被重写、插表或修改，需先解锁。下一节会跳过没有独立正文的纯目录分组。整章确认锁定仍可使用。
  4. 本轮全部处理完，点击“保存本轮修改并生成版本”。系统把本轮累积内容统一保存成一个可下载版本。继续编辑下一轮后再保存，才增加下一个版本。

已暂存内容在刷新页面或重启工作台后恢复；尚未暂存的输入仍有离开页面提醒。导出失败保留暂存，修复后可重试。暂存期间编辑区不提供当前稿下载，旧稿仍可在“版本记录”下载。最终正式组稿仍须通过既有完整性及专业复核检查。

从上传Word/PDF中选择图片插入报告

  1. 无需重新上传已有资料。进入“编写与修订”，展开“文档图片库”，选择Word或PDF来源文件，系统自动识别并展示缩略图。
  2. 可放大预览并选择图片；PDF由文字和线条构成的图、扫描页或组合图，可切换“PDF原页图件”保留完整图文。Word中的矢量/特殊对象暂不能独立转换时，可先导出PDF后使用原页。
  3. 编辑图题，选择本章的目标小节，再选择小节末尾或具体段落之后，点击“插入到所选位置”。可切换章节，把同一张图放到其他章节。
  4. “本章已插入图件”可调整位置/图题或移除此图。插入、调整和移除只更新本轮编辑暂存，最后点击“保存本轮修改并生成版本”才生成含图Word。来源文件和原图不因移除而删除。

图片出处保存在报告追溯记录中，不向模型发送图片。若改写导致原定位段落改变或重复，系统会提醒重新选择；导出暂移文末并提示，不静默丢图。已确认锁定的小节或章节需先解锁才能调整图件。后续改写会保留已插入图片，但仍需核对位置是否适用。

图表插入正文中间（2026-11-25）

图片和表格都可以按“前文 → 图表 → 后文”的顺序编排。先把前后文字分别保留为两个段落，再选择前一个段落作为插入位置。

  • 图片：展开“文档图片库”，选择图片、小节和“在此段之后”，再点击插入。已插入图片用“调整位置/图题”重新选择；“定位正文”可跳到实际显示处。
  • 原表：展开“复用资料中的原表”，选择原表、小节和插入段落。已有表格切换“编辑正文”，使用表格上方的“表格正文位置”调整；随后暂存当前编辑。
  • “阅读排版”直接显示按位置排列的正文、原表和图片。“编辑正文”中可展开“图文排版预览”，同时保留原有的文字和表格编辑控件。
  • 未指定段落的图表放在所属小节末尾。同一段落后有多个新插入图表时，按插入或调整的先后顺序排列。
  • 如果插入段落被删除、改写或重复，预览会提示重新选位置；图片导出会按原有规则转入待核对图件，表格保留在所属小节末尾。请在最终保存前重新定位。
  • 所有修改仍留在本轮编辑中；点击“保存本轮修改”后才形成可下载版本。旧下载文件不会自动改变。

删除章首堆积内容及批量删除正文

在“编写与修订”的阅读模式下，每段文字上方都有复选框、“编辑此段”和“删除此段”。可以只勾选需要移除的几段，再点击上方“删除所选段落”。删除先进入本轮编辑，点击“暂存当前编辑”后持久保存；全部编辑完成再统一保存版本。

如果内容堆积在第一个小节前，在“当前编辑小节”中选择“章首正文（未归入小节）”，即可单独处理。删除正文不会删除原始上传文件；锁定内容需要先解锁。页面若已有未暂存修改，请先暂存，再刷新加载新界面。

附件自动附入及原件预览

报告附件章中的“附件1…”和“附图1…”是清单。系统会根据清单在当前项目已上传资料中自动查找对应原件：独立PDF或图片、Word原报告附件中的证照图片及原表；图纸包优先按已有解析结果中的逐页图名对应。无需再次上传或逐页手工插入。

进入附件章，向下查看“附件原件 · 自动关联”。展开对应条目可预览原表、证照和PDF原页，也可以下载来源文件。多页文件通过预览下拉框翻页，预览一页不代表只会附这一页；例如76页MSDS会整体保留。

完成编辑后，统一保存本轮修改，再下载新版本，实际原件才会附入Word。旧下载文件和旧版本不会自动改变。仅有清单名称、原件缺失或版本无法明确时会提示；组合绘图的独立位图可能漏掉叠加文字或箭头，看到完整性提示时请对照原件，必要时补充PDF原页。明确停用或设置不附原件的文件不会自动采用。

组稿检查、目录页码与PDF下载

点击“检查并组装总稿”后，会立即弹出检查窗口。显示“暂不能生成正式总稿”时，请在窗口中查看具体章节和原因；这表示检查未通过，并非按钮失效。完成正文、处理缺项并确认锁定后，再检查和组装。不要把未完成章节直接标记通过来跳过审阅。

统一保存本轮修改或组装总稿时，系统会附入附件、计算目录页码并生成对应PDF，界面会显示等待提示。此步骤不调用模型，请勿重复点击。保存后可下载Word和分页PDF，历史版本中也会显示对应PDF下载入口；旧下载文件不会自动更新。

本机需要安装官方LibreOffice（https://www.libreoffice.org/download/download-libreoffice/）。macOS默认识别/Applications/LibreOffice.app；Windows识别Program Files内的LibreOffice；Linux识别soffice/libreoffice命令，项目Docker镜像包含排版组件。特殊安装位置可由部署人员设置SAFETY_OFFICE_PATH。组件缺失时系统会提示，正式总稿不会伪造目录页码。

Word保存了已计算的目录，并使用打印布局。跨电脑字体差异可能引起Word重排；需要固定版式演示或打印时优先查看同版PDF。排版失败时已有版本和本轮编辑会保留；页面会显示错误原因。

查看每段正文的引用来源

在“编写与修订”中选择章节和小节，每段文字上方点击“查看来源”（位于“编辑此段”旁）。编辑正文模式的段落操作区也提供该按钮。窗口展示本段文字、引用的文件名称、位置及已保存的原文快照；无引用或快照缺失时明确提示。查看来源不调用模型，也不修改报告。

原文可能仅是旧报告中的同一句结论，这只能说明文字来自哪里，不能证明政策适用或符合性已经核实。人工改写后也要重新核对原有引用是否还支持新表述。

审核状态与报告使用条件

知识卡片区分“已审核”与“可用于报告”。审核通过并不代表资料能够支持任何项目结论：还要符合适用范围、来源状态、版本及有效日期。点击未纳入原因查看具体缺项。同一法规的不同条文应采用一致分类，不要改成历史案例来绕过法规检查。

一次审核确认可用

新界面使用“审核通过并启用”：核对来源、适用范围和版本有效性后完成一次审核，即确认条目可用，无需再单独选择“现行有效”。审核提示会说明法规“未核验”随本次确认启用的含义；已明确废止、被替代或不在有效日期内的条目不能直接启用。历史已审核但未核验记录不自动代签，核对后可用同一按钮确认。

知识问答与报告依据分开：已审核待核验的条文可用于解释原文，回答会提示有效性尚未核验；不能据此认定现行有效或项目符合。报告依据仍要求满足有效性条件。不需要在完成该次确认后重复维护同一有效状态。

公共资料不全或法规可能陈旧时

  1. 打开左侧“共用知识维护”，找到“公共资料发现与更新”。
  2. 不知道找什么，点击“按项目推荐资料”，查看基础法律、安全设施、重大事故隐患、消防及行业专项等候选主题。地方规定依据已确认项目地址推荐；没有地址时，可以在补充检索词里填写省市和法规主题。
  3. 想检查现有法规，点击“检查库内法规更新”：不超过6项时会直接开始检查，进度和候选显示在下方“检查与搜索结果”；超过6项时先勾选最多6项再点击“搜索所选主题”。每次选1—6个主题，也可手工输入公共检索词；页面显示的这些词会发送给搜索服务，项目文件不会上传。
  4. 点击“搜索所选主题”，等待页面显示官方来源候选。点击标题可以查看官网，点击“下载资料”保存文件：PDF/DOCX保存原文件，网页保存提取的正文TXT。网页中的图片附件不自动包含在TXT内，请打开官网另行下载需要的原附件。
  5. 需要加入知识库，点击候选下的“导入公共库待审核”。系统保存来源并解析正文；重复导入会提示，不会覆盖旧资料。核对法规名称、版本、实施日期、适用条件后，再用现有审核功能启用。

推荐是资料准备线索，不代表每一项都适用于项目；更新搜索目前提供官方发布和变更线索，仍需核对是否替代原版本。没有搜索结果不代表原资料现行有效。下载失败或页面不能提取正文时，可打开官网自行下载后使用“导入公共资料”。本功能不调用写作大模型，无需额外模型API Key，但需要网络连接。

新版界面：知识资料与报告编写

左侧导航是主要入口。共用知识维护分成三个独立页面：

  • 知识资料：查看总量、待审核和可供报告检索的数量；按关键词、分类、状态筛选。列表默认显示摘要，点击标题查看完整内容及来源；点击“编辑”打开独立编辑窗口，保存仍按原规则生成待审核修订。
  • 联网发现与更新：左侧选择主题、检查法规和输入检索词，右侧查看进度、官方候选、来源链接、下载及导入按钮。
  • 上传与导入：导入公开文件，不必翻过其他列表或编辑表单。

已有报告时，编写页优先呈现草稿。目录维护移至下方折叠的“目录管理 · 编辑、新增或删除章节”，仍可展开新增、删除及排序；生成设置保留在独立折叠面板中。目录、正文、编写助手分区显示，窄屏自动调整排列。页面视觉样式不会改变Word导出的排版规则。

字体与文字大小

在同一“外观”窗口中选择：

  • 字体风格：跟随主题、现代黑体、正式宋体、霞鹜文楷。每项有实际字体样张，选择后立即预览。宋体与文楷使用随软件提供的本地字体。

设置保存在当前浏览器，刷新后保留；换浏览器或清理网站存储后需重新选择。上述设置只影响工作台显示，不修改报告正文、审核结果、模型配置或Word/PDF导出格式。

导航、快捷前往与界面图形

各主题的导航、功能图形及部分图标采用对应风格；同一主题切换知识问答、资料、编写、计算和历史时，页头图形也随功能变化。这些图形是界面装饰，不是项目证据，不进入报告。

知识核对与专注正文

知识库顶部的“全部知识”“待审核 / 待核对”“可用于报告”现在可以直接点击筛选。“报告使用待核对”表示条目可能已审核，但现行有效性或其他报告使用条件仍需确认，不能只看审核通过就当作报告依据。此展示不会替用户修改审核结果。

点击知识标题打开右侧详情，可同时继续使用列表；按Esc或点击“关闭”收起。列表中的简短标题不改变原始来源和定位。没有匹配结果时可点击“清除筛选”。

报告纸张顶部点击“专注正文”，收起目录、助手和章节辅助工具，放大正文阅读区域；点击“退出专注”或按Esc恢复。阅读排版中只显示正文及已插入图表，图片库和原表插入工具可在“编辑正文”模式中使用。保存、确认、版本生成及导出规则沿用原流程。

在窄屏上，左上角菜单按钮展开导航抽屉；点击功能后自动收起，避免导航占据正文首屏。知识分类页签、专业分类页签及主题选项支持方向键和Home/End切换。

项目资料一览与原件预览

项目概览、资料导入或图件与位置页面提供“项目资料一览”，显示当前真实文件类型及数量。“展开图件预览”按需显示最多4份PDF或图片，优先图件；PDF预览为第1页，可放大查看或下载原件。其他页和报告图件插入仍使用“文档图片库”或“PDF原页图件”；首屏缩略图不代表整份附件只保留一页。

测试记录、项目回收站与更新

“项目交付 → 测试记录”展示仓库中的 最新测试记录 及历史全流程记录。界面不会自动从GitHub拉取文件；同事拉取最新代码后刷新，才能看到同步后的记录。开发测试通过不等于四类真实报告均已完成专业验收。

项目列表的垃圾桶图标用于移入回收站，操作前按提示确认项目名称。需要恢复时进入回收站。移入回收站与删除某个上传文件是不同操作；操作前确认当前项目和选中范围。

更新代码前先暂存编辑，等待任务结束。用Git部署的项目在仓库目录执行 git pull，再按部署方式加载新版本；仅前端资源或手册更新时刷新网页或重新打开离线手册即可。后台更新按启动说明重启服务。不要用覆盖整个data目录的方式更新程序。
