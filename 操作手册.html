1 启动与进入工作台

  1. 在 Finder 按 Command + Shift + G，输入 /Users/lijie/Desktop/work/safety-report-agent。
  2. 双击 启动工作台.command，等待页面打开。
  3. 若浏览器未自动打开，访问 http://127.0.0.1:8765。
  4. 看到后台运行成功提示后，可以关闭终端窗口。无需保持聊天或 Codex 开启。

更新后请刷新页面。电脑重启或退出系统登录后，下次使用再次双击启动。结束使用时，等待任务完成并保存编辑，再双击 停止工作台.command。

127.0.0.1 仅指当前这台电脑。同事共用需要公司服务器地址，不能把这个本机网址直接当作公司共享地址。

2 先配置并选择编写模型

不配置模型只能生成编写提纲，不能自动写出完整的报告正文。

  1. 点击左侧“模型设置”，或者“草稿预览与编写”中的“配置或添加模型”。
  2. 在“已保存配置”选择“添加新模型”。
  3. 选择服务商：DeepSeek、通义千问、本机 Ollama 或自定义兼容服务。
  4. 填一个容易识别的配置名称，例如“公司报告编写模型”。
  5. 检查 API 服务地址。百炼的地域与工作空间地址需要和自己的 Key 匹配。
  6. 输入自己的 API Key。本机 Ollama 通常不需要 Key，但需要提前运行模型服务并安装模型。
  7. 点击“获取模型列表”，在“模型 ID”中选择；供应商不支持列表接口时，填写其控制台提供的准确模型 ID。
  8. 点击“测试连接”。它只发送一条测试文本，不发送项目资料。
  9. 测试通过后点击“保存并选用”。随后可以在编写区域切换已保存的模型。

Key 在设置窗口填写即可，不要发送到聊天中。服务端保存设置，重启后仍可使用；页面不会回显已经保存的 Key。修改已有配置时，Key 留空表示保持；更换服务地址或服务商时需重新填写，避免把原供应商密钥发给新地址。

模型来自你配置的服务，而非程序自带的免费大模型。保存成功表示配置已保存，不等于连通性和正文质量已验收；建议先测试连接，再用演示项目验证编写效果。

3 继续已有项目 不需要重新开始

进入页面后，点击左侧已有项目即可。原来的上传文件、手工填写和旧草稿保留在项目中。

  1. 在“资料与项目信息”中查看文件列表和读取状态。
  2. 需要补充资料时，继续点击“选择文件”或“选择文件夹”。
  3. 同一个内容的文件会跳过重复导入；某个文件无法接收时，其余文件仍继续导入。
  4. 点击“读取新增资料并更新信息”。系统复用已读取的资料，保留人工填写的字段。
  5. 新资料出现不同候选值时，相关字段会提示重新核对，不自动用新值覆盖旧值。

补充资料只会提示草稿需要更新，不会删除旧草稿或下载文件。之后可只改有关章节，也可以直接编辑一段文字。

4 导入时选择正确用途

用途适合什么资料系统怎么使用
自动识别用途混合文件或整个文件夹按格式及名称初步分类，之后可以调整
本项目事实资料项目说明、工艺、设备物料清单、备案等可读取的文字用于事实提取与编写
参考报告或文风样例上一个项目的报告、写作样例保留为参考，不把其中企业和参数作为新项目事实
需要放入报告的图件地理位置图、消防图、设备布置图等设置图题、页码和是否放入 Word
仅归档原始附件CAD 原图、暂不能解析的办公文件等保存并支持原文件下载，不声称已经读懂

文件列表中的用途下拉框可以修改分类。“暂不使用”会使文件退出本次编写范围，保留文件本身；需要时点击“重新纳入”。变更事实资料范围后，要重新读取。

每个文件最大 80 MB；一个项目最多 100 个文件、总计 600 MB。Word、PDF 和文本资料可解析，图片可作图件。旧 DOC、部分办公格式和 CAD 原图可归档，但需要转换后才能用于正文读取或图件嵌入。

5 核对项目基本信息

读取后，系统显示建设单位、项目名称、项目地址、建设性质、生产规模、总投资和建筑面积。

  1. 对照原资料检查候选值，缺项可以手工填写。
  2. 正确的字段勾选“已核对”；也可以在检查完所有已填写内容后，点击“确认已填写项”。
  3. 点击“保存信息”。修改字段后需要重新核对。
  4. 生成时若仍有已填写但未确认的字段，会弹出确认窗口，而不是忽略这些字段。
  5. 可选择“返回核对”，或确认弹窗列出的内容后继续。

建设单位和项目名称必须填写。其他未提供的参数不会自动编造。展开“资料出处与读取提示”查看文件读取问题、候选来源和资料片段。

“使用所选模型辅助提取基本信息”是可选项。勾选后点击读取，会将相关资料片段发送到所选模型；不勾选时使用本地提取和人工核对。

6 导入已有图件与工程文件

点击“已有图件与位置资料”右侧“上传图件或原图”，可直接选择已有文件，不必重新画图。

文件类型可以做什么
PNG、JPG、WEBP、BMP、TIFF预览、设置图题、选择放入 Word
PDF 图纸预览指定页、按页码选择并转换为图片放入 Word
DWG、DXF保存原图并下载；先从 CAD 导出 PDF 或图片后，再上传用于预览与嵌入
SVG保存原图；当前请先转换为 PNG 或 PDF 用于 Word
DWL、DWL2自动跳过，提示寻找同名 DWG 或其 PDF/图片版本

DWL/DWL2 是 AutoCAD 创建的临时信息文件，不是实际图纸。不要通过改后缀把它当作 DWG。

每张图件可以设置图题、PDF 页码，并勾选“放入报告”，然后点击“保存图件设置”。PDF 页码可以写 1、1,3-5，每个文件最多选择 20 页。

预览时请检查图纸是否完整、方向是否正确、文字是否清晰。图件设置保存后，重新生成草稿或点击“保存本章为新版本”，导出的 Word 会使用当前选择的图件。历史版本保留当时已导出的图件，不随新设置变化。

没有现成图件时，可以展开下方工具，生成工艺流程图或在配置地图服务后获取位置图。图片/PDF 图件的接收和展示，不等于已经进行图纸内容理解或工程尺寸识别。

资料版本、知识库与措施承接

  • 在文件列表展开“资料类型、来源、日期与版本”，为备案文件、SDS、综合分析报告、图纸等补充类别、日期和版次。保存后如这些材料用于正文，应重新读取资料；冲突值仍需人工确认。
  • 在“安全知识库”维护跨项目复用的法规标准、危险物料、分析规则、安全措施、报告规则和案例。每条记录应有来源、适用范围和版本；法规/标准需核实有效状态。新条目先待审核，只有审核人批准后才参与生成检索；修改后会退回待审核。
  • 生成报告时知识库只能支持一般依据、规则和方法，不能证明本项目事实。法规有效状态由专业人员核验，当前没有自动法规同步。
  • 在“安全对策措施承接台账”将综合分析报告设置为相应资料类型并读取资料后，可抽取建议候选。逐条核对出处，填写采纳状态、设计落实内容或不采纳理由和确认人。只有已决定条目进入第 4 章；待确认项不会被写成已采纳。

专业分析与计算复核台账

资料页下方的台账可登记危险因素、危化品、重大危险源、防火间距、爆炸危险、泄压面积和消防用水等记录。当前提供 GB 18218-2018 重大危险源辨识指标计算：单一品种按 q≥Q，多品种按 S=Σ(qᵢ/Qᵢ)，每项数量和临界量都需以吨录入并记录来源；系统不会自动识别化学品、选取临界量、划分单元或进行等级分级。计算只保存为待复核记录，专业人员核对单元、分类、临界量和数量口径后，填写复核信息并标记通过，才会作为报告证据。其余计算类型目前只提供结果追溯台账，没有自动公式。报告核对清单会汇总未确认事实、资料冲突、措施漏引、计算漏引、图纸版本缺项和报告过期等提示。

7 第一次智能编写

  1. 在“草稿预览与编写”中，选择已经配置的“编写模型”。
  2. 选择“智能编写正文”。
  3. 本次处理范围选择“全部章节”。
  4. 在修改要求中说明语气和重点，例如“使用正式、简洁的工程报告语言，归纳多份资料，避免重复，不粘贴整段原文”。
  5. 点击“生成并预览新版本”。
  6. 按需确认基本信息，等待进度结束。
  7. 在下方“草稿预览与编辑”逐章检查，然后导出 Word。

模型会根据检索到的证据组织文字、表格与标题。缺失的技术参数列入核对清单。模型不能替代专业设计和技术审核，连接实际模型后的报告质量仍需要结合真实项目评估。

“仅生成编写提纲”不调用模型，只整理写作框架与已确认信息，不再把资料全文拼贴成报告。提纲和正文草稿会在页面及 Word 标题中明确区分。

8 已有一版后怎么继续修改

情况一 只改几句话或补充一段

  1. 打开“草稿预览与编辑”，选择有关章节。
  2. 在文本框中直接修改文字。
  3. 新增内容时点击“补充一段内容”，选择所属小节并填写。
  4. 表格内容可以直接修改；需要新增设备等记录时，点击表格下的“增加一行”。
  5. 点击“保存本章为新版本”。其余章节保留。

切换编辑章节时，会先保存当前未保存的编辑。页面关闭或刷新前仍建议主动保存。直接点击当前版 Word 导出时，也会先保存未保存的章节修改。

情况二 补了一份设备清单 只让模型改相关章节

  1. 回到“资料与项目信息”，继续上传新清单。
  2. 点击“读取新增资料并更新信息”，核对发生变化的字段。
  3. 打开“草稿预览与编写”，选同一模型或另一个已保存模型。
  4. 范围选择“仅修订选择的章节”，勾选有关章节。
  5. 修改要求填写“保留原来的项目背景，补充新设备清单，不修改其它章节”等明确要求。
  6. 点击“生成并预览新版本”，检查新结果。

服务端会把原章节作为修订底稿。未选章节原样保留；新版本保留旧内容需要的证据快照。只改部分章节不代表其他章节已经对新资料重新审核，页面可能继续提示资料有更新。

情况三 新版本没有上一版好

  1. 打开“版本记录”。
  2. 可以直接下载各版 Word 和核对清单作比较。
  3. 找到合适版本，点击“恢复为新版本”。
  4. 确认后，该版内容成为当前草稿，原来各版仍保留。

恢复报告不会把新上传的资料删除或退回旧资料。选定旧稿后，可以继续基于现有资料修改。

9 下载与审核

文件用途
Word可编辑的正文、表格和已选图件
核对清单 HTML可直接阅读的缺失项、审核事项和资料出处
内容与证据 JSON完整章节内容及证据快照，便于技术追溯

Word 正文不再逐段显示证据编号、缺项和调试提示；这些内容移到独立核对清单。空的小节不会反复插入占位句。

下载后检查公司和项目是否正确、工艺和参数是否对应、图件是否清晰、表格是否完整。目录可在 Word 中更新。当前仍需完成最终逐页排版和技术内容验收。

10 PDF 扫描件与无法读取的文件

本机新版已安装文本 PDF 解析、图片处理和 PDF 图件渲染依赖，启动入口会优先使用项目自己的 .venv 环境。

扫描件没有文本层时，仍需要 OCR；当前没有把 OCR 能力冒充成已读取的文字。PDF 可以作为图件展示，并不代表其中所有文字、表格和尺寸都已被准确提取。请查看逐文件读取状态和提示。

旧版 Word DOC 如需提取正文，请在 Word/WPS 中另存为 DOCX。损坏、加密或内部格式不匹配的文件，需要修复或重新导出。失败的文件不会阻断同批次其他文件的接收。

11 保存 备份与停止

资料、配置和版本保存在项目根目录的 data/。模型密钥也在此目录的服务端设置文件中，备份应由项目管理员保管。

  1. 等待任务结束，保存当前编辑。
  2. 双击“停止工作台.command”。
  3. 备份整个项目文件夹，或按 README 中 Docker 卷备份方式操作。
  4. 下次双击启动，继续选择左侧项目使用。

升级前的源码和项目数据另有升级备份；不要把 backups/ 当作可随意删除的临时资料。不要在运行时手工改 data/ 中的文件。

日常操作速查

双击启动 → 配置或选择模型 → 新建或继续项目 → 补充资料 → 读取更新 → 核对信息 → 设置图件 → 全文编写或按章修订 → 页面编辑并保存 → 导出正文和核对清单 → 等任务结束后停止。

本轮更新操作

更新后先双击“停止工作台.command”，再双击“启动工作台.command”，并刷新浏览器，加载新的后台程序。原有资料和历史版本会保留。

页面顶部可以通过“整理资料、核对信息、逐章编写”进入主要操作。文件详情可登记来源单位、日期和版本；保存后重新读取资料。生成前资料检查显示进度，可点击“停止资料检查”。

在“专业分析与计算复核台账”中展开重大危险源指标、厂房泄压面积或单场景消防用水量工具，输入数值及来源后计算。结果先保存为待复核；专业人员核验依据、适用条件、输入和结果，填写复核信息后才能作为报告证据。
