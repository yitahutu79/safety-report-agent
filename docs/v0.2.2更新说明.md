# v0.2.2 更新说明

模型编写前，每章检索的输入限制为最多 18 条、每条最多 1200 字符，减少资料过量时照抄原文的倾向。生成后检查“资料摘录”标记、正文中的表格原文，以及段落与所引用来源的文字相似度；发现问题时向模型追加一次改写。仍未通过的章节不会被保存为新内容。首次生成有任何章节失败时，整份新版本不提交；修订旧稿时，如果未选章节仍有摘录内容，也不会提交混有旧摘录的新版本。

报告核对清单会说明是否完成上述自动检查。检查只能筛出明显的摘录和过度相似内容，不能替代专业人员核实事实、分析逻辑、法规适用性和工程结论。已有的 v0.2.0 草稿保留为历史版本，需要重新选择“全部章节”生成新版本。
