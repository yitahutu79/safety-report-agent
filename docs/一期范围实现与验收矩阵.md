# 安全生产 AI 项目第一期：实现与验收矩阵

版本：v0.9.0（本地原型）  
目标场景：安全设施设计报告辅助编制。报告仍须专业人员审核、定稿和签署。

本文把项目一期企划逐项映射到当前代码，区分“可操作的原型能力”和“已经达到业务验收”。代码中有功能不等于准确率或工程适用性已经通过真实项目验证。

## 建议的真实样本验收方式

1. 由业务人员选定并脱敏至少一组完整样本，冻结项目资料、报告模板、知识条目版本和人工核对答案；样本须覆盖 PDF/Word、跨页表、扫描页、图纸及至少一组冲突资料。
2. 先单独测字段提取：按字段统计正确率、召回率、来源定位正确率；冲突资料单独记“冲突识别率”。对关键事实逐条人工复核，不用整体平均分掩盖危化品最大储量等高风险字段错误。
3. 再测检索和报告：记录每章应有的事实、依据、措施和表格；分别检查有无来源、来源是否支持结论、缺项是否显式、措施是否逐项闭环。报告语言质量由业务专家盲审。
4. 对每一种工程计算单独冻结公式/规范版本和人工金标准，使用边界值、单位换算、缺失值和冲突值测试；未经书面确认的公式不进入生产路径。
5. 由公司确认量化阈值后才签验收。当前没有提供人工标注金标准，因此本项目不宣称抽取准确率或报告完整性已经达到某个百分比。

## 生产化前置事项

此版本便于在一台电脑上验证操作链路。供公司多人长期使用前，需另行完成服务器部署/迁移演练、账号及项目级权限、数据库与备份、并发任务队列、审计留存、内网模型或供应商数据审批、日志脱敏、OCR/CAD 组件、监控告警与恢复测试。不要把本地原型目录直接共享给多人并发写入作为正式生产部署。
