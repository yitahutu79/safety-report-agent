# 专业语言与开源项目整合说明

## 当前生效的功能

智能编写章节时，编写模型会收到专业报告通用语言要求，以及安全设施设计、安全预评价、安全验收评价、生产安全事故应急预案各自的阶段性写作要求。模型审稿阶段检查术语、口语、套话、事实阶段、数字、单位、否定和适用条件；如有问题会触发一次定向返修。非常绝对的安全用语会进入人工复核提示，不自动修改正文。模型仍可能误判，不能代替专业复核。

项目和公共知识库已有关键词检索加入 GPT Researcher 0.17.0 的 BM25 排序实现（已按中文分词和本地检索改造），向量检索仍采用原有 Qdrant/FastEmbed 与结果融合。未检索到关键词时不会使用任意证据凑数；仍需人工标注样本、对照测试召回率与准确率，不能据此声称效果已提升。

## 源码与实际启用范围

`third_party/gpt_researcher/gpt-researcher-source-5cdad9cb.tar.gz` 是固定提交的完整 GitHub 源码压缩包；`third_party/gpt_researcher/upstream-0.17.0` 是固定版本 PyPI wheel 的完整内容。两者分别固定版本，并非同一版本。当前实际用于本应用的包括经过适配的本地 BM25 排序、资料筛选流程和参考上游的审稿流程。资料筛选仅对现有证据标记用途，筛选失败时保留全部证据；每章可能新增一次模型调用。筛选结果保存在报告 JSON 和核对清单，编辑页面的资料筛选记录可供查看。其他组件包括上游网页、联网搜索、爬虫、MCP、发布和报告生成尚未全部整合或运行。公司资料不能默认传给这些功能。

中文技术写作 Skill 的上游原文和 MIT 许可证位于 `third_party/tech_doc_style_chinese/`，其事实保真、术语与表达规则已按安全报告需求适配，未直接执行其环境操作指令。

上游 Python 包的元数据和实际 LICENSE 对许可标识存在不一致，且其依赖涉及额外许可；对外交付前需核验并提供适用的第三方许可和 NOTICE。未安装、未运行完整上游依赖，桌面打包脚本会复制 third_party 源码和许可证，但各平台安装包尚需重新构建并测试。

## 样本效果验证

选择双方确认的非敏感或获授权样本，按报告类型选择相同章节、相同资料和模型，与调整前结果比较：术语、事实与阶段、语言规范性、缺失提示、引用支撑、模型调用次数及时间。由专业人员逐项评审并记录修改意见；不要以通用写作规则或模型自评代替验收。
