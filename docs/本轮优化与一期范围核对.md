# 一期范围核对与本轮优化记录

依据：`AI辅助安全生产项目一期建设范围.docx`。本记录区分功能实现与双方样本验收；测试通过不代表专业结论已经通过验收。

| 一期内容 | 本轮状态 | 仍需核验或补充 |
| --- | --- | --- |
| 资料管理 | 文件保留分类、用途、来源单位、日期、版本和使用状态；支持增量读取 | 扫描文件 OCR、CAD 内容识别和复杂跨页表的识别能力仍有限 |
| 基础数据与出处 | 提取候选及文件位置，支持人工确认与冲突提示 | 应以双方确认的样本逐项核验准确率、召回率和来源位置 |
| 知识库与检索 | 维护分类、来源、版本、效期、审核状态及历史修订；Agent 的检索问题可查询项目资料和已审核知识 | 法规有效性与适用范围需人工核验；官方更新接口尚未接入实际数据源 |
| 专业分析与计算 | 保留可复核台账；辅助计算重大危险源指标、单场景消防用水量、厂房计算段泄压面积。每项输入须有来源，结果初始为待复核 | 危险因素、化学品识别、防火间距、爆炸危险的自动判定仍未完成；上述三个计算器仅覆盖各自明确限定的公式和输入。需工程师核实场景、数值、依据版本和计算过程，并以人工金标准验证 |
| 措施承接与报告 | 综合分析报告建议候选、逐条采纳台账、按章生成和修订、历史版本与报告导出 | 须用完整样本核对措施遗漏率、章节完整性和 Word 版式 |

## 本轮操作变化

- 工作台增加项目工作进度导航，放大常用文字并调整窄屏布局。
- 生成前资料检查成为后台任务，显示进度并可停止；切换项目会清理项目专属的章节提示词及补充答复。
- 资料及图件未保存修改在刷新时保留；生成前需先保存这些设置。文件可登记来源单位或提供人。
- 模型资料规划失败时，使用章节标题和子节继续检索，并在 Agent 记录中标明；生成失败显示实际原因。
- 由 Agent 规划的问题会检索项目资料和已审核知识库；知识库结果仍不能作为项目事实。
- 重大危险源指标计算结果不再自动标记为依据已核验；计算器记录均需由专业人员确认规则有效性。

## 两项新增辅助计算的依据和边界

1. 消防用水量计算按 `V = 3.6 × Σ(qᵢ × tᵢ)` 将人工选定的同一建筑、同一火灾场景的同时作用系统汇总。q 使用 L/s，t 使用 h；系统不选择系统组合、火灾次数、多建筑最大场景，也不计算消防水池最终容积。公式参考 [GB 50974-2014，3.6.1](https://js.119.gov.cn/group1/M00/00/2B/ZYS-ZGGB9XCAAdbNAA3fvxwUOIs217.pdf)。
2. 厂房计算段泄压面积按 `A = 10CV^(2/3)` 计算；V 使用 m³，C 使用 m²/m³。人工核定危险物质类别、C 值、长径比、分段及专项规范适用性，公共截面不自动计入，也不自动检查构件和布置要求。参考 [GB 50016-2014（2018年版），3.6.4](https://js.119.gov.cn/202111/715323810e37465891fc6a5f66b9589d_c_3d35986ea8ea4ce781db.html)。

结果均向上保留三位小数，初始法规状态为未核验，保存为待复核；只有资料齐全并经专业人员复核的记录才可进入报告证据。以上依据需在实际项目中重新核验现行状态与适用性。
