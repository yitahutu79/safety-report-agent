# v0.7.0 更新说明

本次把第一期企划从“只有知识库”扩展为几条可以实际操作的业务闭环：项目资料元数据、更多项目事实字段、共享审核知识库、RAG 检索、安全对策措施承接台账，以及验收边界说明。

- 项目文件可记录资料类别、日期和版本；读取后将元数据带入证据上下文，提示模型遇到不同来源/版本冲突时交由人员核实。
- 知识条目区分草稿、审核通过、停用，支持有效期、法规状态、审核人和历史修订；只有审核通过且当前有效的条目参与检索。
- 报告章节同时检索项目事实和通用审核知识，并明确两类证据用途不同。
- 综合分析报告可抽取安全建议候选；人工决定并填写设计落实或不采纳理由后，才进入安全建议章节证据。
- 增加《一期范围实现与验收矩阵》，说明已实现、未实现和真实样本验收要求。专业计算器和法规自动同步尚未启用，避免使用未确认规则生成确定结论。

验证结果以本次代码测试记录为准。真实项目抽取准确率、完整性和最终排版仍须业务验收。
