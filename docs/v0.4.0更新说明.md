# v0.4.0 更新说明

这次更新针对“整份报告塞满资料摘录、失败后仍导出旧正文、无法从一章开始”的问题调整生成流程。

- 新项目可以从任意一章开始生成；默认选中第 1 章，也可勾选多章或切换到整份报告。
- 未生成的章节在草稿中保持待完成状态，Word 会显示待完成提示。
- 生成失败或未通过内容检查的章节，Word 不会混入旧版正文；工作台仍保留旧稿供查看和重试，历史版本不删除。
- 逐章通过后，报告标记为尚未完成；全部章节完成后才显示整份报告已完成检查。
- 已有项目可以增补资料后只重写相关章节，无需重新上传全部文件。

建议每章都先核对资料依据、项目事实、分析结论和缺项，再继续下一章。模型生成质量还取决于资料检索结果和所选模型，专业结论仍需工程人员审核。
