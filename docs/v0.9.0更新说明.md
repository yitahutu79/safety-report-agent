# v0.9.0 更新说明

本版把章节生成改为 LangGraph Agent 图编排，并保留现有 OpenAI 兼容模型供应商配置、Qdrant 检索和报告版本机制。

- **资料规划 Agent**：按章节结构和用户修改要求生成短检索问题。
- **证据检索工具**：只查询当前项目已有资料索引，返回仍带来源定位的证据；Agent 无任意文件系统或网络访问权。
- **报告撰写 Agent**：依据项目证据、已确认事实、章节 Skill 和适用知识库内容生成结构化正文。
- **质量审核 Agent**：调用确定性引用、结构、标题和可读性校验；发现问题时图路由到一次定向返修，仍失败则沿用现有失败保护，不保存不合格新版本。
- 页面展示本章 Agent 角色、动作和校验状态，不暴露模型隐含推理。生成进度与停止按钮沿用现有机制。
- Agent 图使用项目现有模型 API 配置，不启用 LangSmith 或其他外部追踪服务。

## 当前边界

本版已将 Agent 图接入章节主生成链路，但图的运行状态暂不使用 checkpoint 持久化；进程中断后需重新发起该章节。每章至少比直接生成增加一次资料规划模型调用，审核失败时最多再调用一次返修，实际质量与成本需用公司认可的样本集验证。缺资料事项仍由现有交互补充窗口处理。

新电脑安装时，按 README 使用 `pip install -r requirements.txt`，会安装 LangGraph。
