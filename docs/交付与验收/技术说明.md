# 技术说明（v0.9.0 工作稿）

## 1. 软件定位

本软件面向安全技术人员，辅助安全设施设计报告资料整理、知识检索、受控分析记录、章节草稿生成和质量核对。输出为人工审核的草稿，不代替专业判断、签字盖章或审批。

## 2. 逻辑架构

- **界面**：HTML/CSS/JavaScript 单页工作台；用户通过浏览器访问本机服务。
- **服务端**：Python HTTP 服务，管理项目、资料、章节任务、版本和导出。
- **文档与证据**：解析器提取 DOCX、文本型 PDF、表格与文本，保留来源文件和定位；图件独立管理。
- **知识检索**：项目证据与审核知识分离；Qdrant 本地向量索引与中文关键词检索融合。
- **模型调用**：使用项目中配置的 OpenAI 兼容 Chat Completions 接口；模型选择、密钥和任务取消由工作台管理。
- **Agent 编排**：LangGraph `StateGraph` 在单章内编排资料规划、受限检索工具、撰写、质量审核及至多一次返修；Agent 没有任意 shell、文件系统或互联网工具。
- **受控输出**：现有代码校验引用 ID、章节标题、JSON 结构、可读性问题和项目版本状态；失败不覆盖上一版。
- **持久化**：当前开发版项目数据和版本存储在本机文件目录；Qdrant 使用本地目录模式。正式多人部署需采用经评审的服务端数据库/对象存储和访问控制。

## 3. 关键技术边界

- 当前已实现的确定性专业计算范围应以 `docs/v0.8.0更新说明.md` 为准；其他分析计算需专业人员提供并复核输入、规则、公式和结果。
- 当前 LangGraph 图尚未启用持久 checkpoint；服务进程中断后，正在进行的章节需要重新执行。
- 当前模型服务需由使用方配置并可访问；离线部署、模型权重与许可证、并发性能和准确率尚未通过甲方验收。
- 当前文档扫描件 OCR、CAD 语义理解、官方法规自动更新、多用户身份/权限体系不应描述为已完成能力。

## 4. 软件版本与可复现信息

每次正式测试/交付应填写：应用版本与源码提交/包 SHA-256、操作系统和硬件、Python/依赖锁定文件、模型提供方与模型 ID、模型参数、提示词与 Skill 版本、知识库快照、数据集编号与文件哈希、任务时间、输出文件哈希、测试人员和复核人员。
