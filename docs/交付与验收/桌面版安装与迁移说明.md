# 桌面版安装、启动与迁移说明

软件版本：v0.9.0（内部验证包）  
状态：macOS ARM64 试制包已构建并启动验证；Windows/Linux 安装包须在目标系统原生构建并验收后发布。

当前“安设智编”图标及名称为试制品牌。正式交付前需替换为双方确认的产品名称、公司标识和品牌规范。

## 1. 产品形态

桌面包包含品牌图标、桌面窗口、启动画面、前端界面、Python 本地服务和报告功能依赖。运行时服务只绑定 `127.0.0.1`，不向局域网开放；关闭桌面窗口会结束本地服务。模型 API 仍由管理员/使用者在设置页配置。

## 2. 支持矩阵与构建要求

| 平台 | 构建产物 | 本机运行条件 | 当前状态 |
| --- | --- | --- | --- |
| macOS ARM64 | `.app`，随包提供安装手册 | macOS WebKit；数据存于 `~/Library/Application Support/AnSheZhiBian/` | 已构建；桌面窗口和本地服务启动验证通过。尚未公证签名 |
| Windows x64 | `.exe` 目录包 ZIP | Windows 10/11、Microsoft Edge WebView2 Runtime；数据存于 `%LOCALAPPDATA%\\AnSheZhiBian\\` | 构建脚本准备好；需 Windows 原生机器构建和验证 |
| Linux x64 | 目录包 `.tar.gz` | 需桌面环境及 Qt WebEngine 运行库；数据存于 `$XDG_DATA_HOME/AnSheZhiBian/` 或 `~/.local/share/AnSheZhiBian/` | 构建脚本准备好；需目标发行版原生构建和验证 |

PyInstaller 产物必须在各目标系统分别构建，不能用当前 Mac 的包代替 Windows/Linux 版本。对外正式发布前，应由甲方提供代码签名/公证证书或确认其软件分发流程；当前包未签名，Windows 也未打包为带安装向导的 MSI/Setup。

## 3. 从源码构建桌面包

在目标系统安装 Python 3.13 和对应 WebView 运行环境后，在项目根目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-desktop.txt
.venv/bin/python -m pytest
.venv/bin/python tools/build_desktop.py
```

Windows PowerShell 将虚拟环境解释器写为 `.venv\\Scripts\\python.exe`。构建结果位于 `dist/`，交付包同时含应用目录、操作手册、安装说明、技术说明、现场演示脚本和构建清单。构建脚本会生成压缩包 `.sha256` 校验文件。交付时应把各平台原生构建结果、校验值与测试记录一起归档。

Linux 的桌面 WebView 使用 Qt WebEngine；不同发行版需验证系统显示、图形驱动、字体和 Qt 动态库。Windows 应优先通过企业软件分发/离线安装包确保 WebView2 Runtime 存在。

## 4. 使用和退出

1. 将对应操作系统的交付压缩包解压到本地应用目录。
2. 首次启动时按本公司终端策略允许应用运行；如策略阻止未签名软件，应由管理员签名或加入批准的软件分发流程。
3. 在“模型设置”中配置已批准的模型服务；密钥保存到当前用户数据目录。
4. 按《操作手册.html》创建项目和导入资料。
5. 关闭应用窗口即可停止桌面进程；确认任务结束后再关窗。

## 5. 数据迁移与备份

当前浏览器开发版数据位于源码目录 `data/`，桌面版数据按操作系统存放在上表路径。迁移前停止旧工作台并做完整备份；复制数据时需同时迁移项目目录、知识库数据和 `settings.json`。该设置文件可能含模型密钥，应通过受控加密渠道传输，只允许授权人员读取。跨平台迁移后，应验证项目列表、资料引用、版本、知识索引和模型设置，再继续使用。

卸载应用包不会自动删除用户数据。若要清理数据，应按公司数据留存策略单独审批并备份。
