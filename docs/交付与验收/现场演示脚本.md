> 演示前确认使用的资料已获准用于现场展示；模型地址、账号和密钥已由管理员配置；现场网络、WebView 运行环境和输出目录可用。未确认的数据不得带入演示。

| 步骤 | 演示操作 | 可观察结果/验收点 | 应留存记录 |
| --- | --- | --- | --- |
| 1. 安装与启动 | 在目标平台按安装说明运行桌面程序 | 出现产品图标、启动画面、工作台；本地服务只监听本机 | OS/硬件、安装包哈希、启动日志、界面截图 |
| 2. 模型配置 | 选择双方批准的服务与模型，运行不含项目资料的连接测试 | 连接状态、模型名称可见；密钥不在界面/API 明文回显 | 模型服务标识、模型 ID、连接结果（不得记录密钥） |
| 3. 项目资料 | 新建项目，导入确认的数据集，选择文件用途 | 显示文件、用途、版本和读取状态；失败文件有原因 | 文件清单、SHA-256、解析警告、处理参数 |
| 4. 基础信息 | 读取资料，核对字段候选及来源定位，确认或标记冲突 | 金标准字段、来源位置、冲突/缺失提示可复核 | 字段级对比表、抽取结果与人工基准 |
| 5. 知识查询 | 检索一条审核通过知识和一条项目事实 | 通用知识与项目事实可区分；来源、版本/有效状态显示 | 查询词、召回结果、证据 ID、来源定位 |
| 6. 专业记录 | 打开代表性计算/分析记录及复核信息 | 输入、单位、依据、过程、结果和复核人齐备；未复核结果不作为受控正文证据 | 独立复算表、边界条件、复核签名 |
| 7. Agent 章节编写 | 选择一章；展示资料规划、项目内检索、撰写、审核工作记录 | 记录显示角色/动作；正文有来源 ID；结构与表达通过已确认检查 | Agent trace、模型/Skill/配置版本、调用耗时/用量（若供应商提供） |
| 8. 缺项与人工补充 | 选择预设资料不足的样本，确认系统提出问题并填写补充 | 不支持的关键结论列为缺项；补充答复带待核实状态 | 缺项清单、答复、证据映射、人工确认 |
| 9. 修订与取消 | 修改一章或在模型调用过程中停止 | 只修改选择章节；取消不覆盖上一版 | 版本差异、取消日志、前后版本哈希 |
| 10. 报告导出 | 导出 DOCX 与核对清单，现场打开检查 | 章节、表格、图件、目录及追溯附件符合双方确认的模板条款 | 输出文件、哈希、页数、版式截图、问题列表 |
| 11. 备份恢复 | 备份测试项目，再恢复到干净测试环境 | 资料索引、报告版本、配置按约定恢复 | 备份包哈希、恢复步骤、耗时、数据校验 |
