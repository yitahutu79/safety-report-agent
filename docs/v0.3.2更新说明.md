# v0.3.2 更新说明

- 诊断确认：OpenRouter 上配置的 MiniMax M3.1 Flash 以 `finish_reason=length` 结束，达到章节请求的 8,000 token 上限，导致输出 JSON 被截断。
- 针对该模型请求增加 `reasoning.max_tokens=1200` 并从响应中排除推理文本，为可见章节 JSON 留出输出预算；其它模型不改变请求参数。
- OpenRouter 的推理 token 计入 completion token 上限，模型支持推理参数及 `response_format`，但不提供 JSON Schema 强约束。[模型参数说明](https://openrouter.ai/minimax/minimax-m3.1-flash%3Afree/)、[OpenRouter 推理 token 说明](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens)。
- 诊断只调用了一次第 1 章所需证据。返回结果只在内存中做了格式校验，没有保存或覆盖报告。
