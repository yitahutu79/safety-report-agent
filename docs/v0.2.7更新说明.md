# v0.2.7 更新说明

- 兼容模型响应在合法 JSON 前后附带的说明文字、Markdown 代码围栏及分段文本，减少“正文已返回但整个章节被 JSON 解析拒绝”的情况。
- 全部所选章节均失败时不再生成一个仅由旧章节组成的新版本；已有报告保持原样，页面显示失败原因。
- 部分章节失败而其他章节成功时，失败章节明确标记为旧版内容，逐章预览会展示失败原因；整份报告不再标成全部通过质量检查。
- 按 Agent Skills `SKILL.md` 目录格式增加 7 个章节技能，并在章节初稿及重写请求中装载对应技能。

本版本还没有接入向量知识库或混合 RAG。详见《技术栈评估与升级蓝图》，后续需在批准的历史项目资料上评测 RAGFlow 和 Qdrant，再决定生产检索后端。
