# v0.8.0 更新说明

本版继续补齐一期验收中“专业分析计算可追溯”和“质量检查”的工作流。

- 新增专业分析/计算台账，覆盖危险因素、危化品、重大危险源、防火间距、爆炸危险、泄压面积、消防用水等条目类型。
- 新增 GB 18218-2018 重大危险源辨识指标计算：单一品种按 q≥Q，多品种按 S=Σ(qᵢ/Qᵢ)；数量与临界量以吨输入并要求分别记录来源。计算仅生成待复核记录，不判断化学品分类、临界量选择、单元边界、混合物适用性或重大危险源等级。
- 每项可记录输入值与单位、来源文件/定位/证据 ID、规范来源和版本条款、公式/判定方法、过程、结果、适用边界、复核人和修订历史。
- 未复核记录不会作为报告证据；“专业复核通过”记录缺少来源、依据、公式/过程、结果或复核人时无法保存。
- 逐章生成时，相关章节可读取复核记录；提示词要求只转述记录、不另行计算或改写结果。
- 报告核对清单增加确定性质量检查：未确认事实、字段冲突、引用缺失/无定位、章节待补充、措施承接漏引、计算漏引、图纸缺少日期/版次、资料变更后报告未同步、引用知识库法规未标记为现行。

本版仅实现上述 GB 18218 指标计算，尚未实现消防水量、泄压面积、防火间距、爆炸危险分析等确定性工具。其他台账条目将人工/外部核算结果及复核过程纳入追溯，不能被描述成自动计算器。后续需由公司核定各正式公式来源、适用条件、单位、边界测试和人工金标准，再开发受控的确定性计算插件。

依据核对：国家标准信息公共服务平台当前将 [GB 18218-2018 标记为现行](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=E976F49B263D7579CCABD419B1E40225)；标准第 4.2.1、4.2.2 条及公式（1）见[自治区工业和信息化厅公开的标准文本](https://gxt.gxzf.gov.cn/ztgz/ywzt/mybzwp/mybzphybz/P020211104617225153098.pdf)。状态于 2026-11-03 核对。项目使用时仍须复核标准适用性、化学品分类与表项。
