# 信息化建设实施方案：工程范围与当前状态

本清单仅整理软件建设，不涉及合作或收益分配。所有报告输出均为待专业人员审核的草稿；试用章节不能等同正式行业模板或法规适用性判断。

## 一期工贸及管理资料

| 工作项 | 当前代码状态 | 后续工程工作 |
| --- | --- | --- |
| 安全生产数据库 | 本地资料管理、知识条目、人工审核和混合检索原型 | 多用户身份、项目及文档授权、操作审计、加密部署和备份恢复尚待建设与测试；不能承诺绝对防止数据外流 |
| 工贸安全条件论证 | 已增加试用项目类型、章节、专业记录和来源关联 | 依据已确认样本细化论证方法、行业边界、报告格式及案例验证 |
| 工贸安全设施设计 | 原有设施设计报告原型、部分计算及措施承接 | 与工贸场景样本、适用规则和模板逐项核验；不能直接假定覆盖所有行业 |
| 工贸验收报告 | 原有安全验收评价试用类型及现场/整改记录 | 明确客户所指验收报告具体类别，核对现场资料与格式后再确认适配；不能假定名称相同即可替代 |
| 标准化管理资料 | 已增加试用项目类型、目录和制度、检查、自评记录 | 不同行业版本、执行证据、台账模板及真实样本验证 |
| 双重预防机制 | 已增加试用项目类型、风险管控和隐患整改记录 | 风险分级方法、行业地区要求及隐患闭环验证 |
| 生产安全事故应急预案 | 原有试用目录与风险、应急组织、响应和资源记录 | 样本、资源调查、专项预案、现场处置及专业复核 |
| 工贸安全现状评价 | 已增加试用项目类型、现状核查、评价方法及整改记录 | 评价方法、当前运行现场证据、专业模板与真实样本验证 |

## 二至四期

- 化工类条件论证、设施设计、设施竣工验收评价和安全现状评价：应以一期平台为基础，建立独立的项目类别、法规版本、化工专属规则与样本；现有通用试用类型不代表已实现化工业务。
- 职业卫生类预评价、防护设施设计、控制效果评价和防护设施验收：目前无对应完整业务流程，需要职业卫生专业数据、方法、模板及专家验证。
- 可行性研究、环评、消防评估、环境应急预案：目前无对应完整业务流程，需要各自的专业输入、规则、数据权限和审核流程。

## 跨类型与质量

- 现有项目目前绑定单一报告类型；不同报告直接复用已确认项目事实、逐项映射和追踪版本的跨报告项目模型尚未完成。禁止直接把另一报告的设计状态、历史数据或结论当成现状事实。
- 现有法规适用性和有效状态由人工核验；自动发现官方更新、差异比对、提醒、审核和历史版本切换仍需实现。任何自动信息不得直接替代未经复核的适用性判断。
- “完成 85%/90%”必须依据确认的代表性资料、人工金标准、可执行度量和缺陷定义测试。目前没有证据证明系统已达到这些数字。
- 目前的报告类型和章节均为试用结构。尚未完成四类旧合同场景或本方案一期范围的专业样本闭环、质量验收及生产部署测试。
