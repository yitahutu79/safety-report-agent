# 四类报告专业工作记录说明

当前版本在“资料与项目信息”页面提供“专业工作记录”。此功能是专业人员整理证据、复核并将记录关联至指定章节的工作台，不自动代替现场核查、计算、评审或专业判断。

## 使用步骤

1. 新建项目并选择对应报告类型，上传、读取项目资料。
2. 在“专业工作记录”选择工作类别，填写标题、工作内容、过程、条件、来源文件及具体位置。类别是提示清单，应结合项目实际判断是否适用。
3. 按工作类别填写专属分项，例如验收现场核查填写设计要求、现场实际情况和核查日期，整改记录填写状态和复查证据。系统自动建议主章节编号；可填写当前模板中的其他主章节编号。分项不完整时可先以“待复核”保存。
4. 专业人员核实内容与来源，填写复核人及标为“复核必填”的分项，将状态调整为“专业复核通过”并保存。修改会保留历史修订；未复核、复核不通过的记录不会作为专业记录证据送入模型。
5. 前往草稿编写，选择对应章节生成或重写。系统会把该章节已复核记录附带来源送入章节工作流；原有其他章节保留。完成后检查正文的来源关联和质量提示。
6. 记录更新后，已有报告会提示需要更新；请选择受影响章节重新编写。最终结果仍需核对与人工审核。

## 各报告的提示类别

- 安全设施设计：危险因素与设计条件、安全设施设计与依据、设计参数与专业复核；原有措施承接与计算台账仍可使用。
- 安全预评价：评价范围、危险因素、评价单元及方法、评价过程和对策建议。
- 安全验收评价：实际建设情况、危险因素、现场核查、检测检验、整改复查和评价过程。设计资料不能单独证明设施已经建成或合格。
- 应急预案：风险情景、组织职责、预警报告、响应处置、应急资源、培训演练和专项/现场处置方案。联系方式、资源数量等应以核实材料为准。

## 当前边界和后续工作

- 上述类别及章节为暂定工作提示，并非适用于所有项目的强制清单；正式目录、方法和范围需要结合各类型样本、行业和双方验收方案确认。
- 现已为各类工作记录提供专属分项字段和章节证据关联；专业算法、法规适用性审查、全流程自动化和专业人员验收仍未完成。
- 本功能记录人工填写的来源文件及位置，但不会自动证明文件存在、内容真实或复核人身份有效；使用时应对照原始资料复核。
- 预评价方法选择及分析、验收评价现场证据和整改闭环、应急预案资源与响应细节仍需在真实样本基础上继续细化，并进行完整大模型生成、人工比对和验收测试。
- 增加或修改代码后需停止并重新启动工作台；本地服务不自动加载这些改动。外部模型调用前应按合同确认项目资料传输范围。

旧版已复核记录会继续保留；缺少新增分项时质量检查会提示补充，编辑并重新标记复核通过时需要填写必填分项。整改状态尚未记录为“复查通过”时，质量检查会提示继续核查。


## 法规标准适用性与距离计算

四类项目的“专业工作记录”都有“法规标准适用性核查”。选择后记录标准编号、版本、条款、项目适用性判断、适用理由、有效状态、核验日期和来源；复核前应核对项目事实及权威来源。报告质量检查会比对可识别的正文标准编号与本项目已复核记录，并提示无记录、待确认或失效状态。系统设置的核验超过 365 天提示是内部提醒，不是法规规定的有效期限；规则无法覆盖所有法规名称、地方规范和专业适用条件，也不会自动核实最新版本。

安全设施设计项目的“专业分析与计算复核台账”中新增“距离差值辅助计算”。输入实际或图示距离和人工选定的参考距离及来源，系统仅计算两数之差并保存为待复核；它不选择防火间距条款、不核定测量基准、不判断是否合规。负差值只是输入差额，不是合规结论。

修改已复核的专业记录内容后，新修订会自动退回待复核，需专业人员重新核验。法规和计算均应由专业人员确认有效版本和适用范围。
