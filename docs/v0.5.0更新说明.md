# v0.5.0 更新说明

- 已有报告默认进入按章选择，章节勾选项直接显示；未勾选章节不会调用模型。
- 章节编辑区增加本章自然语言修改要求和“按本章提示词重写”按钮。
- 章节编辑区增加资料补充顾问。它依据本章缺项、审阅意见及检索到的项目证据生成按优先级排序的材料清单，不会写报告正文或保存新版本。
- 用户可逐项填写已确认的补充信息；生成时这些内容只传入对应章节，并作为“待核实”证据留有出处标记。上传的资料仍需先读取，再重写章节。
- 支持新增自定义章节和删除章节；每次结构调整保存为新版本，历史版本可恢复。删除模板章节会影响导出结构，完整检查状态会清除。

模型清单是写作准备建议，不是法规要求清单，也不替代专业人员审核。
