# 双知识库 RAG 与评测操作说明

## 当前实现及边界

本机原型分为当前项目资料和公共安全专业知识：项目资料在各自项目目录中，公共知识在共享知识条目中；检索测试可明确选择其一，报告编写可以分别检索当前项目资料和已审核公共知识。公共资料上传后均为待审核；法规条目只有经过审核并标记为现行、且在所填有效期内，才可能参与公共知识检索。项目文件不会自动复制到公共知识库。

本原型尚无独立账号、项目级授权、加密存储和完整审计。项目目录隔离只是检索范围隔离，并非公司多人协作的权限安全保障；在实现和验证这些能力之前不要把此原型当作安全的多人服务器部署。公有知识条目应确认公开属性、授权、准确性与来源后录入；公开内容不代表自动适用或自动现行。

项目及公共知识使用中文关键词与 Qdrant/FastEmbed 本地语义检索，按融合排序返回；如果语义索引或模型不可用，会显示关键词回退。首次使用可能需要获取向量模型，离线环境需提前配置模型。检索评测不调用正文大模型；实际报告编写若选择外部模型，会向所配置服务发送选中的证据，应先确认资料外发范围。

## 一、导入公司项目资料

1. 启动工作台，创建或选择对应项目。
2. 在“资料与项目信息”选择文件或文件夹，选择“本项目事实资料”，然后点击“读取新增资料并更新信息”。
3. 检查文件读取状态和资料出处；扫描件、旧版 DOC、图纸等可能无法直接解析。历史报告应设为参考资料，不能直接当作新项目事实。
4. 当前项目的资料只在该项目检索测试中作为项目证据。不同项目即使属于同一公司，也不会在此次项目检索中自动合并。

## 二、导入公共专业资料

1. 打开任一项目后，选择“安全知识库”。
2. 在“导入公共资料”选择分类和有权使用的公开文件；支持 DOCX、文本型 PDF、TXT、Markdown 和 CSV，每次 1 个文件、最多 20 MB、100 个内容块。扫描文件需先 OCR；太长文件应先拆分，系统不会只导入前 100 块。
3. 导入后在下方“知识条目与审核”逐条检查内容、来源、适用范围、版本；法规标准还须编辑为经核验的现行状态，之后填写审核人并审核通过。
4. 只有审核且符合有效状态、日期过滤的条目可进入公共检索；审核不代表系统自动证明法规对任何具体项目适用。

## 三、测试检索效果

1. 在“安全知识库”找到“双知识库检索与评测”，选“公司项目库·当前项目”或“公共专业知识库”。
2. 输入测试问题，点击“检索候选”，查看来源、位置与正文，勾选人工判断与该问题相关的证据。候选列表最多显示 20 条，可暂时更换检索词寻找遗漏，再将问题改回要测试的问题。也可手工补充已知证据 ID。
3. 输入返回数量 K，点击“计算当前问题的指标”。Precision@K = 命中的相关证据数 / K；Recall@K = 命中的相关证据数 / 该问题全部人工标注的相关证据数。返回不足 K 条时，Precision@K 的分母仍为 K；接口额外返回按实际返回条数计算的精确率。
4. “保存本题到本次评测”可收集多题，同一范围和同一 K 值显示宏平均；“下载本次评测 JSON”保存问题、范围、K、证据 ID、指标和检索模式。页面关闭或切换项目时未下载的评测记录不会保留。
5. 应事先独立阅读资料，尽可能标全相关证据并固定样本版本；仅标注检索结果中的内容可能使召回率虚高。文件更新、知识修订后证据 ID 可能变化，需重新标注。检索 P/R 不等于报告事实准确率，也不能直接说明整篇报告合格。

## 四、开源选型

- [Qdrant](https://github.com/qdrant/qdrant)：项目已有 Qdrant 本地向量索引，继续复用；向量检索失败时保留关键词回退。
- [RAGFlow](https://github.com/infiniflow/ragflow)：调研过其文档处理和 RAG 方向，本轮未部署或接入；评估接入前需验证部署资源、许可证及权限需求。
- [Docling](https://github.com/docling-project/docling)：可作为复杂 PDF、表格和 OCR 的后续解析候选；本轮未安装或接入，模型许可证和本地处理能力需单独核验。
- [Haystack 检索评测说明](https://github.com/deepset-ai/haystack/blob/main/docs-website/docs/optimization/evaluation/statistical-evaluation.mdx)：本轮参考了人工标注检索评测的思想，指标由本项目本地代码计算；并未安装 Haystack。

## 五、尚待完成

完整双库建设还需多人认证与授权、文档级权限、数据库迁移与加密、备份恢复、审计、正式 OCR、知识来源及版本管理、可重复导入的持久化标注集和大规模测试。当前未完成真实样本准确率和召回率评估，也不能声明任何验收数值。
