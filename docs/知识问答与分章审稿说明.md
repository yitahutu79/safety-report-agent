# 知识问答与分章审稿

## 知识问答

1. 启动工作台，打开或创建项目，在“安全知识库”页找到顶部“知识问答”。
2. 选择“公共专业知识库”或“公司项目库·当前项目”。公共知识须先完成审核；法规标准还需核验现行有效和适用范围。项目知识须先上传并读取。
3. 选择已配置模型，输入问题，点击“检索并回答”。系统会显示模型服务地址；确认发送后，问题和检索片段将发送给所选模型服务。
4. 查看回答、待确认事项和引用来源。生成中可点击“停止回答”。未检索到证据时不会调用模型。回答会保存在当前项目状态中，显示最近一次结果。
5. “检索结果标注与评测”用于人工标注证据并计算检索指标，不负责回答问题。

引用编号仅表明模型选择的来源，不能证明内容得到来源支持；请核对原文件、版本和适用条件。当前没有多人项目权限控制。不要把私密项目材料交给未经授权的外部模型。

## 逐章撰写与审稿

智能编写时，系统对每个选中章节规划检索、撰写、运行结构及来源校验，然后参考 GPT Researcher 的 Reviewer Agent 对草稿与证据进行模型审阅。如发现问题，最多定向返修一次，再检查；未通过时保留原有版本。每章新增至少一次模型调用，处理时间和费用可能增加，审稿也可能误判，仍由专业人员复核。

第三方代码出处、改造说明和许可证见 `third_party/gpt_researcher/`。当前引入的是审稿组件的适配，不是整个 GPT Researcher 系统，也未完成四类真实项目的效果和验收验证。
