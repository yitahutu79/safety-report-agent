# v0.3.0 更新说明

> 后续流式输出错误诊断已在 v0.3.1 修复，见《v0.3.1 更新说明》。

- 新增 Qdrant 本地持久化项目索引，使用 FastEmbed 的中文 `BAAI/bge-small-zh-v1.5` 向量模型。
- 项目检索改为中文关键词召回与向量语义召回的 Reciprocal Rank Fusion (RRF) 融合。标准编号、设备位号等精确字符串仍由原关键词索引覆盖。
- 每个项目单独保存向量库至 `data/<项目ID>/knowledge/qdrant/`。分析资料时重建索引；生成报告复用索引。升级已有项目后重新分析一次即可建库。
- 首次分析需要下载 FastEmbed 模型；下载失败时保留关键词检索并在资料警告中显示原因，不会伪称语义检索成功。
- 项目章节继续从可移植的 `skills/safety-facility-design/chapter-*/SKILL.md` 读取技能指令。

当前版本采用应用内 Qdrant Local 作为单机模式，后续公司服务器可通过 Qdrant HTTP 服务替换存储后端。RAGFlow、LangGraph 工作流、Ragas 评测集与 RLHF/DPO 数据闭环仍是后续接入项，不能把产品调研或 `SKILL.md` 当作它们已经落地。RLHF 是用人工反馈训练/对齐模型的方法，不是推理时可插拔的功能；本版不会自动训练或改变模型。

向量检索改善相关资料召回，不验证规范适用性，不判断设计合规，也不保证生成质量；设计人员仍需核实每条证据、分析和结论。
