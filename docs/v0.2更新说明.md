# v0.2 使用流程改进

本次修改针对实际试用中发现的原文拼贴、核对字段静默丢失、无模型入口、图件难导入及无法持续修订的问题。

| 问题 | 本次行为 |
| --- | --- |
| 没有确认的字段被忽略 | 生成前显示待确认字段，服务端拒绝静默跳过；支持确认已填项 |
| 离线内容直接粘贴原文 | 改为明确标注的编写提纲；智能正文要求用户选定模型，并在提示中要求归纳改写 |
| 模型不能选择 | 网页设置供应商、地址、密钥、模型 ID；可获取模型列表、测试和保存多项配置 |
| 已有图件没有入口 | 增加专门图件上传、PDF 页码、图题、嵌入选择、预览与原文件下载 |
| DWL2 不能用 | 识别为 CAD 临时文件并说明真实 DWG 或导出图件的选择方法，批量导入继续处理其余文件 |
| 新增文件后报告被删除 | 保留当前草稿，标记资料更新，按哈希复用已解析文件，保留手工值 |
| 一版写得不够好需要全重来 | 支持原稿修订、只选部分章节、直接补段落/改表格、新增表格行与版本恢复 |
| Word 正文像调试输出 | 证据编号、缺项和审阅事项移入独立可阅读核对清单；空小节不反复插入占位句 |
| 本机 PDF/PNG 功能未启用 | 安装项目独立虚拟环境依赖，并让启动入口优先使用该环境 |

升级保留已有项目及全部上传资料；原报告归入历史版本。新版本不会自动用任何云服务处理真实资料，需要使用者在页面配置模型并发起编写。连接测试使用单独的无项目资料文本。

正文质量不能只靠界面修补保证。新流程提供可靠的模型入口、章节证据与原稿上下文、审核和修订能力；连接真实模型后，还需用公司项目评估内容质量、完整度和专业正确性。扫描件 OCR 与最终排版验收仍未完成。
