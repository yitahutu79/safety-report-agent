# v0.2.3 更新说明

用户指出资料摘录只能用于查证，报告正文必须经过筛选、归并、分析和编辑。智能编写现在要求模型返回简短的资料编辑记录：按主题标明“采用并整理 / 省略 / 待核对”，并列出证据来源；正文只能引用已标记为采用的证据。该记录单独放在核对清单里，不进入 Word 正文。

每章仍按最多 18 条、每条最多 1200 字符向模型提供资料。随后检查摘录标记、表格原文混入正文及与引用来源过度相似的段落，最多追加一次定向重写。首次编写有章节不合格时不提交报告；修订时若未选择的旧章节仍含摘录式内容，也不提交混合版本。检查没有替代事实、逻辑和专业结论的人工审查。

已存在的旧稿仍保留。请刷新工作台，选择“智能编写正文”和“全部章节”重新生成；新的编辑记录会出现在独立的核对清单中。生成过程会调用模型，可能产生相应用量。
