# v0.2.4 更新说明

修正 v0.2.3 对模型输出格式要求过严的问题。实际测试发现，所选模型返回了章节正文，却没有按指定格式附带 `editorial_plan`，因此系统拒绝提交，页面只短暂显示错误。

现在模型如有返回编辑记录，工作台会校验并保留；兼容模型未返回时，工作台会从正文引用生成透明的“已引用 / 未直接引用”证据使用清单，不再因缺少这个可选字段而阻断报告。核对清单会标明记录是模型提供还是根据正文引用整理。明显照抄的正文仍会触发一次重写，重写后仍不合格则保留旧版并提示原因。失败原因也会固定显示在页面提示栏。

原报告版本未被修改。刷新页面后可重新生成；此操作会调用已配置模型，并可能产生相应用量。
